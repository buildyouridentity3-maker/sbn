# SBN Student Knowledge

Student learning content is stored in `content/students.json`.

To add a new lesson:
1. Open `content/students.json` on GitHub.
2. Add another object using the same fields:
   - `id`
   - `category`
   - `title`
   - `class`
   - `excerpt`
   - `content`
   - `questions` (optional)
3. Commit the change.
4. Refresh the website.

You do not need to edit the bundled JavaScript for normal content updates.
